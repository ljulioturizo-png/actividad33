# ACTIVIDAD 3 DE PRACTICA

## Descripción
Para hacer esta actividad xploramos el entorno de desarrollo integrado (IDE) Visual Studio Code, con el propósito de conocer sus principales herramientas y aprender para qué sirve cada una. Identificamos el editor de código, que es el espacio donde escribimos y modificamos los programas; el explorador de archivos, que permite organizar y encontrar los archivos del proyecto; y la terminal integrada, que sirve para ejecutar comandos sin necesidad de salir del programa.

También reconocimos los diferentes menús, como Archivo, Editar y Ver, los cuales ofrecen opciones para crear y guardar archivos, modificar el código y organizar la interfaz de trabajo. Esta exploración nos permitió comprender mejor cómo está organizado Visual Studio Code y cómo podemos utilizar sus herramientas.

## personalizacion de interfaz
Después de explorar los componentes principales, revisamos las opciones de personalización de Visual Studio Code para adaptar el entorno a nuestras necesidades. Estas opciones permiten cambiar el tema, ajustar el tamaño de la letra, organizar los paneles e instalar extensiones que facilitan el desarrollo de software.

También conocimos la importancia de las extensiones, ya que permiten agregar funciones y herramientas adicionales al editor. Con esta parte de la actividad comprendimos que personalizar el IDE ayuda a trabajar de una manera más cómoda, organizada y eficiente.

## La creacion de carpetas del proyecto
En esta parte trabajamos en la organización de un proyecto dentro de Visual Studio Code, teniendo en cuenta la importancia de mantener los archivos ordenados y separados según su función. Para ello utilizamos una carpeta principal donde se pueden organizar los archivos del código fuente, la documentación y las pruebas del programa.

Por ejemplo, la carpeta src se utiliza para guardar el código fuente, docs para la documentación, tests para las pruebas y el archivo README.md para explicar de qué trata el proyecto. Esta estructura facilita la ubicación de los archivos, el mantenimiento del código y el trabajo futuro sobre el proyecto.

## Conclusion
Con el desarrollo de esta actividad aprendimos a reconocer las herramientas principales de Visual Studio Code, comprendimos las opciones para personalizar su interfaz y conocimos la importancia de organizar correctamente un proyecto de software. Estos conocimientos nos ayudan a utilizar mejor el entorno de desarrollo y a prepararnos para realizar proyectos de programación de una forma más ordenada y profesional.
